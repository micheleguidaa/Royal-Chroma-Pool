**Royal-Chroma-Pool** è un videogioco sviluppato in **Unity** che unisce la strategia del biliardo con l’ambientazione epica dei regni medievali.  
Due fazioni, **Red Kingdom** e **Blue Kingdom**, si sfidano a colpi di stecca per conquistare la vittoria.  

🎥 [Guarda il gameplay su YouTube](https://www.youtube.com/watch?v=UbJTjnaCviE&t=108s)

---

## 🏰 Panoramica

- 🎱 **Pool game fantasy**: un classico biliardo rivisitato in chiave medievale.  
- 🏰 **Ambientazione epica**: castelli, scudi, arazzi e dettagli fantasy.  
- ⚔️ **Doppia fazione**: Red Kingdom vs Blue Kingdom.  
- 🎨 **Grafica real-time** con shader in ShaderLab, GLSL e HLSL.  
- 🕹️ **UI di gioco**: gestione turni, indicatori delle palle rimanenti, pausa, tiro e cambio vista.  

---

## ✨ Features

- Scritto principalmente in **C# (91%)**  
- Shader avanzati in **ShaderLab, GLSL e HLSL**  
- Progetto **open-source** e aperto a contributi  
- Esperienza **single player / locale multiplayer** (da confermare in base allo sviluppo futuro)

## 🚀 Getting Started

### 1. Clona il repository
```sh
git clone https://github.com/micheleguidaa/Royal-Chroma-Pool.git
````

### 2. Apri il progetto

* IDE consigliato: **Unity + Visual Studio**

### 3. Installa dipendenze

* Unity (versione LTS consigliata, es. 2022.x)
* .NET Core / C# support

### 4. Build & Run

* Apri la scena principale in Unity
* Premi **Play** e inizia a giocare!
